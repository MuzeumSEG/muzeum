      Для сотрудников

      • Добавить экспонат
      1. Откройте «Добавить экспонат» и войдите аккаунтом GitHub или по приглашению на почту.
      2. Если изготовителя ещё нет в справочнике, сначала добавьте его в разделе «Изготовители».
      3. В разделе «Экспонаты» нажмите Add entry, заполните поля и загрузите фото: первое лицевая сторона, второе тыльная с клеймом.
      4. Нажмите Save. Через 1–2 минуты экспонат появится на сайте.
