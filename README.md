# Музей строительных образцов

Сайт-каталог образцов плитки, черепицы, кирпича и кованых гвоздей. Работает бесплатно на GitHub Pages, пополняется через форму Pages CMS.

## Что где лежит

| Папка или файл | Что это |
| --- | --- |
| `_exhibits/` | Экспонаты, по одному файлу на экспонат |
| `_manufacturers/` | Справочник изготовителей |
| `media/exhibits/` | Фотографии |
| `.pages.yml` | Настройка формы пополнения: какие поля видит сотрудник |
| `index.html`, `assets/` | Внешний вид сайта |
| `data/site.json` | Тексты шапки и подвала, контакты (правятся в форме, раздел «Тексты сайта») |
| `data/exhibits.json`, `data/manufacturers.json` | Служебные файлы: GitHub сам собирает из экспонатов список для сайта |
| `tools/` | Скрипты для предпросмотра, на сайт не попадают |

## Как запустить сайт (один раз)

1. Создать организацию на GitHub и в ней репозиторий, например `muzey`.
2. Загрузить в него содержимое этой папки.
3. В репозитории: Settings → Pages → Source: «Deploy from a branch», ветка `main`, папка `/ (root)`. Через пару минут сайт откроется по адресу `https://<организация>.github.io/muzey/`.
4. Зайти на app.pagescms.org, войти через GitHub, установить приложение Pages CMS на организацию и открыть репозиторий. Форма пополнения появится сразу.
5. Сотрудников без GitHub можно пригласить в Pages CMS по почте (раздел Collaborators).

## Как добавить экспонат

Pages CMS → «Экспонаты» → Add entry → заполнить поля → загрузить фото → Save. Через 1–2 минуты экспонат появится на сайте.

Если изготовителя ещё нет в справочнике, сначала добавьте его в разделе «Изготовители», потом выберите в карточке экспоната.

Чтобы временно скрыть экспонат, снимите галочку «Показывать на сайте».

## Перед запуском с настоящими экспонатами

- Удалить демо-экспонаты из `_exhibits/`, демо-изготовителей из `_manufacturers/` и рисунки из `media/exhibits/`.
- В форме, раздел «Тексты сайта»: очистить поле «Плашка вверху страницы», вписать настоящие контакты, при желании поменять название и тексты.

Фото лучше загружать уже уменьшенными: 1600–2000 пикселей по длинной стороне достаточно.
